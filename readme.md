# NIT Meghalaya Student Website

A modern, responsive student-made website showcasing **NIT Meghalaya**, built using HTML, CSS, and JavaScript.

## 🌐 About the Project

This project is a frontend web development project created to practice and demonstrate skills in:

- HTML5
- CSS3
- JavaScript
- Responsive web design
- DOM manipulation
- CSS animations and transitions
- Interactive UI components

The website presents information about NIT Meghalaya, including its departments, academics, student life, and campus-related information in a modern interface.

## ✨ Features

- 📱 Responsive design for desktop, tablet, and mobile
- 🌙 Dark/Light mode
- 🧭 Responsive navigation menu
- 🏫 About NIT Meghalaya section
- 🎓 Departments section with filtering
- 📚 Academics section
- 👨‍🎓 Student life section
- 📊 Animated statistics
- ✨ Scroll-reveal animations
- ⬆️ Back-to-top button
- 🔗 Links to the official NIT Meghalaya website

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, responsive design, animations and layout
- **JavaScript** – Interactivity and dynamic features

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Use **Live Server** or open `index.html` directly in a browser.
